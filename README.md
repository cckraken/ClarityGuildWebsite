A recruitment/management site for a World of Warcraft raiding guild, replacing a Google Form and manual Discord workflow

Built to fix a problem: Applications arriving by webhook, delivery failures going unnoticed, no record of decisions.

Tech stack: .NET 10 Web API, Entity Framework Core, SQL Server, React with TypeScript, Vite, Tailwind, xUnit, Git, GitHub, GitHub Actions (CI/CD)

Status: In progress
